# H7 Usability Study Template

**Hypothesis H7:** Interventions and explanations are useful — faculty usability study completed; SUS ≥ 68.

---

## Study Design

- **Participants:** 2–3 faculty members from the target department
- **Session length:** 45–60 minutes
- **Format:** Think-aloud protocol, moderated

## Tasks

| # | Task | Success Criterion |
|---|---|---|
| T1 | Upload a result PDF and commit valid records | Completes without assistance |
| T2 | Find a student with HIGH_ATTENTION band and explain the contributing factors | Can name ≥ 3 factors |
| T3 | Open the evidence chain for an AI insight and identify the source PDF | Locates source upload |
| T4 | Run a what-if scenario (change one subject mark) and confirm HYPOTHETICAL label is visible | Correctly identifies label |
| T5 | Approve or dismiss an intervention recommendation | Completes workflow |

## Metrics

- Task success rate (%)
- Time on task (seconds)
- Number of errors per task
- Clarity rating 1–5 per task
- System Usability Scale (SUS) score — 10 items, target ≥ 68

## SUS Questionnaire

*(Standard 10-item SUS — administer after all tasks)*

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.
